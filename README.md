# Super-Store-Sale-Dashboard
📊 Super Store Sales Dashboard (Excel)
📌 Project Overview

This project is an interactive Super Store Sales Dashboard created in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and Data Visualization techniques.

The dashboard provides insights into sales performance, order quantity, customer segments, shipping modes, regions, cities, and monthly sales trends. It helps users analyze business performance and make data-driven decisions.

🎯 Objectives
Analyze overall sales performance.
Track order quantity and sales trends.
Compare sales across different shipping modes.
Identify top-performing cities and regions.
Understand customer segment contributions.
Visualize monthly sales distribution.
